Physical setup
Source

Gaussian: an initial displacement with zero initial velocity, not a seismic forcing wavelet.

Numerical settings

Fixed 180 × 116 nodes. Changing spacing changes domain size. Automatic Δt uses CFL 0.6; manual unstable settings are rejected.

Applying a setup resets the wavefield and all receiver samples.

Velocity palette: blue (slow) → ochre (fast).

Inspect one numerical step

Pause and select an interior cell. The five-point stencil uses the current center and neighbors, plus the previous center value.

pnext = 2p − pprevious + v²Δt² (Dxxp + Dzzp + s)

How the update works

Central spatial differences: each second derivative compares the center with its two neighbors, divided by the square of the corresponding spacing.

Second-order time derivative: three time levels approximate acceleration. The previous field is required because the wave equation is second order in time.

Sponge: the damped equation adds 2σpt. The engine uses (2p − (1−σΔt)pprevious + v²Δt²(Laplacian + s)) / (1+σΔt). The inspector shows the undamped PDE value separately.
